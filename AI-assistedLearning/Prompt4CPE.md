# CPE Examination Preparation Guide

## Description

This document contains prompt templates for analyzing CPE (Competitive Programming Examination) problems and preparing for the examination. It provides two versions of prompts:

- **Shorter Version**: A concise prompt for quick analysis of common problem types and trends
- **Longer Version**: A comprehensive prompt with detailed analysis criteria, classification schemes, and strategic recommendations

Both prompts reference the official CPE History Problem List and guide students in understanding problem patterns, identifying study priorities, and predicting potential future exam topics.

## Shorter Version

```markdown
I am preparing for the CPE programming examination.

Please analyze the CPE History Problem List:
https://cpe.mcu.edu.tw/cpe/test_data/problems

Please summarize the common UVa problem types, classify them by topic, identify recent trends, and suggest what topics I should prioritize when preparing for the next CPE examination.

Please also provide a cautious prediction of possible topics for the next exam and explain your reasoning.
```

## Longer Version

```markdown
I am preparing for the CPE programming examination.

Please refer to the CPE History Problem List:
https://cpe.mcu.edu.tw/cpe/test_data/problems

Please help me analyze the previous CPE problems from the following perspectives:

1. Identify the frequently appearing UVa problems.
2. Classify the problems by topic, such as:
   - basic input/output
   - simple math
   - simulation
   - string processing
   - array and sorting
   - map/set/frequency counting
   - matrix and 2D array
   - stack and queue
   - graph traversal
   - dynamic programming
   - number theory
   - geometry
3. Summarize the topic trends in recent CPE examinations.
4. Identify which problem types are suitable for beginners and which are more advanced.
5. Suggest a preparation priority list for students.
6. Based on the historical pattern, predict the possible topics that may appear in the next CPE examination.

Please do not only list problem IDs.  
Please explain the reasoning behind the analysis and provide a clear study strategy for students.
```
