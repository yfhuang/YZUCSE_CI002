# UVa 11063 - B2-Sequence

## Definition

A B2-Sequence is a set of positive integers where all pairwise sums are distinct. In other words, for a sequence $\{b_1, b_2, \ldots, b_n\}$ with $b_1 < b_2 < \cdots < b_n$, the sequence forms a B2-Sequence if all sums $b_i + b_j$ (where $i \leq j$) are unique.

For example, $\{1, 2, 5, 7\}$ is a B2-Sequence because the sums are:
- $1+1=2$, $1+2=3$, $1+5=6$, $1+7=8$, $2+2=4$, $2+5=7$, $2+7=9$, $5+5=10$, $5+7=12$, $7+7=14$

All these sums $\{2, 3, 4, 6, 7, 8, 9, 10, 12, 14\}$ are distinct.

Another example, $\{1, 2, 4, 8\}$ is a B2-Sequence because all pairwise sums are distinct: $\{2, 3, 5, 6, 9, 10, 12, 16\}$.

However, $\{3, 7, 10, 14\}$ is NOT a B2-Sequence because we have duplicate sums: $3+10=13$ and $3+10=13$, or more critically, $3+14=17$ and $7+10=17$.

## Observations

1. **Ascending sequence of positive integers**: A B2-Sequence consists of positive integers arranged in strictly ascending order: $1 <= b_1 < b_2 < \cdots < b_n$. This ordering is essential for the definition and properties of B2-Sequences.

2. **Distinct pairwise sums**: All pairwise sums $b_i + b_j$ (where $i \leq j$) must be unique. This means no two pairs of elements can produce the same sum. If any two sums are equal, the sequence is not a B2-Sequence.

## Brainstorming

### Brute-force method

A straightforward approach to check if a sequence is a B2-Sequence:

1. **Check ascending order**: Verify that the sequence consists of positive integers in strictly ascending order: $1 <= b_1 < b_2 < \cdots < b_n$.

2. **Generate all pairwise sums**: Use two nested loops to compute all sums $b_i + b_j$ where $i \leq j$. Store these sums in a collection (set or hash table).

3. **Check distinctness**: Verify that all sums are unique. If the number of unique sums equals the expected count $\frac{n(n+1)}{2}$, then all sums are distinct and the sequence is a B2-Sequence.

**Time Complexity**: O(n²) for computing all pairwise sums.

**Space Complexity**: O(n²) for storing all sums.

#### C

```c
#include <stdio.h>
#include <stdbool.h>

#define MAX_N 100
#define MAX_SUM 20000

bool isB2Sequence(int b[], int n) {
    bool used[MAX_SUM + 1] = {false};

    // Check positive numbers
    if (n <= 0) return false;
    if (b[0] <= 0) return false;

    // Check ascending order
    for (int i = 1; i < n; i++) {
        if (b[i] <= 0) return false;
        if (b[i] <= b[i - 1]) return false;
    }

    // Generate all pairwise sums and check distinctness
    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {
            int sum = b[i] + b[j];

            if (used[sum]) {
                return false;
            }

            used[sum] = true;
        }
    }

    return true;
}

    int n;
```

```c
#define MAX_N 100

bool isB2Sequence(int b[], int n) {
    int sums[MAX_N * MAX_N];
    int sumCount = 0;

    // Check positive and strictly increasing
    for (int i = 0; i < n; i++) {
```

### Method 4: Tree-based Set Structure (co-work with ChatGPT and verified by UVa OJ)

```c
#include <stdio.h>
#include <stdbool.h>
#include <stdlib.h>

typedef struct Node {
    long long value;
    struct Node* left;
    struct Node* right;
} Node;

Node* createNode(long long value) {
    Node* node = (Node*)malloc(sizeof(Node));
    node->value = value;
    node->left = NULL;
    node->right = NULL;
    return node;
}

bool insert(Node** root, long long value) {
    if (*root == NULL) {
        *root = createNode(value);
        return true;
    }

    if (value == (*root)->value) {
        return false;  // Duplicate found
    } else if (value < (*root)->value) {
        return insert(&(*root)->left, value);
    } else {
        return insert(&(*root)->right, value);
    }
}

void freeTree(Node* root) {
    if (root == NULL) return;

    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

bool isB2Sequence(int* b, int n) {
    // Check positive and strictly increasing
    if (n <= 0) return false;
    if (b[0] <= 0) return false;

    for (int i = 1; i < n; i++) {
        if (b[i] <= 0) return false;
        if (b[i] <= b[i - 1]) return false;
    }

    // Generate all pairwise sums using tree-based set
    Node* root = NULL;

    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {
            long long sum = (long long)b[i] + b[j];

            if (!insert(&root, sum)) {
                freeTree(root);
                return false;
            }
        }
    }

    freeTree(root);
    return true;
}
```

### Method 5: Hash-based Set (Hashing) (co-work with ChatGPT and verified by UVa OJ)

```c
#include <stdio.h>
#include <stdbool.h>
#include <stdlib.h>

typedef struct {
    long long key;
    bool exists;
} HashEntry;

typedef struct {
    HashEntry* table;
    int capacity;
    int size;
} HashMap;

HashMap* createHashMap(int capacity) {
    HashMap* map = (HashMap*)malloc(sizeof(HashMap));
    map->table = (HashEntry*)calloc(capacity, sizeof(HashEntry));
    map->capacity = capacity;
    map->size = 0;
    return map;
}

unsigned long hash(long long key, int capacity) {
    return ((key ^ (key >> 32)) * 2654435761UL) % capacity;
}

bool hashInsert(HashMap* map, long long key) {
    unsigned long idx = hash(key, map->capacity);
    int attempts = 0;

    while (attempts < map->capacity) {
        if (!map->table[idx].exists) {
            map->table[idx].key = key;
            map->table[idx].exists = true;
            map->size++;
            return true;
        } else if (map->table[idx].key == key) {
            return false;  // Duplicate found
        }

        idx = (idx + 1) % map->capacity;
        attempts++;
    }

    return false;
}

void freeHashMap(HashMap* map) {
    free(map->table);
    free(map);
}

bool isB2Sequence(int* b, int n) {
    // Check positive and strictly increasing
    if (n <= 0) return false;
    if (b[0] <= 0) return false;

    for (int i = 1; i < n; i++) {
        if (b[i] <= 0) return false;
        if (b[i] <= b[i - 1]) return false;
    }

    // Generate all pairwise sums using hash table
    int expectedCount = n * (n + 1) / 2;
    HashMap* map = createHashMap(expectedCount * 2 + 1);

    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {
            long long sum = (long long)b[i] + b[j];

            if (!hashInsert(map, sum)) {
                freeHashMap(map);
                return false;
            }
        }

    freeHashMap(map);
    return true;
}
```

### Method 6: Bitmask Optimization (co-work with ChatGPT and verified by UVa OJ)

#### C
```c
#include <stdio.h>
#include <stdbool.h>
#include <stdlib.h>

typedef struct {
    unsigned long long* bits;
    long long max_value;
} BitSet;

BitSet* createBitSet(long long max_value) {
    BitSet* set = (BitSet*)malloc(sizeof(BitSet));

    long long num_words = (max_value / 64) + 1;
    set->bits = (unsigned long long*)calloc(num_words, sizeof(unsigned long long));
    set->max_value = max_value;

    return set;
}

void setBit(BitSet* set, long long value) {
    if (value >= 0 && value <= set->max_value) {
        long long word_idx = value / 64;
        long long bit_idx = value % 64;

        set->bits[word_idx] |= (1ULL << bit_idx);
    }
}

bool testBit(BitSet* set, long long value) {
    if (value >= 0 && value <= set->max_value) {
        long long word_idx = value / 64;
        long long bit_idx = value % 64;

        return (set->bits[word_idx] & (1ULL << bit_idx)) != 0;
    }

    return false;
}

void freeBitSet(BitSet* set) {
    free(set->bits);
    free(set);
}

bool isB2Sequence(int* b, int n) {
    // Check positive and strictly increasing
    if (n <= 0) return false;
    if (b[0] <= 0) return false;

    for (int i = 1; i < n; i++) {
        if (b[i] <= 0) return false;
        if (b[i] <= b[i - 1]) return false;
    }

    // Generate all pairwise sums using bitmask
    long long maxSum = (long long)b[n - 1] + b[n - 1];
    BitSet* set = createBitSet(maxSum);

    for (int i = 0; i < n; i++) {

                return false;

    return true;
}
```

### Issues to Address

1. **Algorithm Efficiency**: Design an efficient algorithm to check if a sequence is a B2-Sequence. A brute-force approach checking all pairwise sums may be O(n²), but optimization techniques should be considered.

2. **Input Validation**: Handle edge cases such as empty sequences, single-element sequences, or duplicate elements that violate the strictly ascending requirement.

3. **Memory Constraints**: For large sequences, storing all pairwise sums in a set or hash table could consume significant memory. Consider trade-offs between time and space complexity.

4. **Computational Complexity**: Determine the maximum sequence length for which the solution is feasible within typical competitive programming time limits (usually 1-2 seconds).

5. **Test Case Generation**: Create comprehensive test cases including valid B2-Sequences, invalid sequences with duplicate sums, boundary cases, and edge cases.

6. **Algorithm Validation**: Verify the correctness of the solution against known B2-Sequences and ensure it properly identifies invalid sequences.
